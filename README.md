# Banking Customer Analysis

## Real-World Finance Data Project

This project performs an end-to-end analysis of banking customer data to understand customer profiles, financial behavior, banking relationships, loyalty segments, and risk patterns.

The project was developed as part of an internship assignment to apply practical data analysis and visualization skills to a real-world finance dataset.

## Project Objective

The main objectives of this project are:

- Understand the characteristics of banking customers
- Analyze customer income and financial behavior
- Compare different banking relationships
- Analyze customer loyalty segments
- Explore banking loans and deposits
- Analyze credit card usage
- Identify risk patterns
- Find correlations between financial variables
- Generate meaningful business insights

## Dataset

The dataset contains customer-level banking information including demographic, financial, relationship, loyalty, and risk-related attributes.

The analysis includes variables related to:

- Customer demographics
- Estimated income
- Bank deposits
- Bank loans
- Credit card balance
- Savings accounts
- Checking accounts
- Properties owned
- Banking relationship
- Loyalty classification
- Risk weighting
